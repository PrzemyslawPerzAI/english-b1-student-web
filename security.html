Bezpieczeństwo i prywatność

English B1 Student Web jest prywatną aplikacją edukacyjną przeznaczoną do nauki języka angielskiego.

Minimalizacja danych

Frontend nie przechowuje haseł do Google, tokenów GitHub ani kluczy administracyjnych. Do przeglądarki powinny trafiać wyłącznie dane potrzebne do bieżącej sesji nauki.

Separacja środowisk

Wersja testowa korzysta wyłącznie ze środowiska DEV. Produkcyjne arkusze i automatyzacje nie są modyfikowane podczas testów.

Dostęp

Docelowy backend wymaga autoryzowanej sesji. Sekrety są przechowywane wyłącznie po stronie serwera i nie są umieszczane w publicznym kodzie strony.

Zasady

Nie publikujemy prywatnych arkuszy Google, identyfikatorów dostępowych, tokenów ani danych administracyjnych. Aplikacja udostępnia tylko minimalny zakres informacji potrzebny uczniowi.
